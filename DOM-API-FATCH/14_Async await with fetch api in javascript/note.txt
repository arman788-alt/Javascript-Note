ধরুন, আপনি রেস্টুরেন্টে গিয়ে খাবার অর্ডার দিলেন। খাবার আসতে ৫ মিনিট সময় লাগবে।

Fetch: এটা হলো আপনার অর্ডার দেওয়ার প্রক্রিয়া।
Await: এটা হলো আপনার ৫ মিনিট বসে অপেক্ষা করা (খাবার না আসা পর্যন্ত অন্য কিছু করবেন না)।
Async: এটা হলো আপনার পুরো টেবিল বা পরিবেশ যেখানে এই ওয়েটিংটা সম্ভব।

২. Async/Await এবং Fetch-এর উদাহরণ
আমরা একটি ডামি API (JSONPlaceholder) থেকে কিছু ইউজারের তথ্য নিয়ে আসব:

Example:

async function getUserData() {
  try {
    console.log("ডেটা আনার চেষ্টা করছি...");

    // ১. সার্ভারে রিকোয়েস্ট পাঠানো এবং অপেক্ষা করা (Fetch)
    const response = await fetch('https://jsonplaceholder.typicode.com/users/1');

    // ২. সার্ভার থেকে আসা রেজাল্টকে JSON ফরম্যাটে রূপান্তর করার জন্য অপেক্ষা করা
    const data = await response.json();

    // ৩. ফাইনাল ডেটা আউটপুট দেখা
    console.log("ইউজারের নাম:", data.name);
    console.log("ইমেইল:", data.email);

  } catch (error) {
    // যদি নেটওয়ার্ক বা অন্য কোনো সমস্যা হয়
    console.log("দুঃখিত, কোনো ভুল হয়েছে:", error);
  } finally {
    console.log("প্রক্রিয়াটি সম্পন্ন হয়েছে।");
  }
}

// ফাংশনটি কল করা
getUserData();
৩. এখানে কী কী ঘটল? (ধাপগুলো লক্ষ্য করুন)
async function: আমরা ফাংশনটির শুরুতে async লিখেছি, যার মানে হলো এই ফাংশনের ভেতরে আমরা await ব্যবহার করতে পারব।

fetch('URL'): এটি একটি রিকোয়েস্ট পাঠায়। কিন্তু ডেটা আসতে সময় লাগে। তাই আমরা তার আগে await বসিয়েছি যাতে ডেটা না আসা পর্যন্ত কোড পরের লাইনে না যায়।

response.json(): সার্ভার থেকে ডেটা সরাসরি পড়া যায় না, একে json() মেথড দিয়ে জাভাস্ক্রিপ্ট অবজেক্টে রূপান্তর করতে হয়। এটাও কিছুটা সময় নেয়, তাই এখানেও await ব্যবহার করা হয়েছে।

try...catch: ইন্টারনেটে কাজ করার সময় অনেক সময় সার্ভার ডাউন থাকতে পারে বা ইউআরএল ভুল হতে পারে। সেই এররগুলো ধরার জন্য আমরা এই ব্লকটি ব্যবহার করি।
